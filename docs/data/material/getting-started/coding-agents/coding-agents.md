# Coding Agents

<p class="description">Install Material UI agent skills in your coding agent.</p>

Material UI ships agent skills for common integration topics—`material-ui-nextjs`, `material-ui-styling`, `material-ui-tailwind`, and `material-ui-theming`—in the repository's `skills/` folder.

## Installation

Install the skills with your coding agent:

<codeblock storageKey="coding-agent">

```bash Claude Code
/plugin marketplace add mui/material-ui
/plugin install material-ui@material-ui
```

```bash Codex
codex plugin marketplace add mui/material-ui
codex plugin add material-ui@material-ui
```

```bash Other agents
npx skills add mui/material-ui
```

</codeblock>
